# iPhone 订阅课表

本目录根据上级目录的 `课表.pdf` 生成西北工业大学 2026-2027 学年秋季学期课表。

## 已采用的学校设置

- 时区：`Asia/Shanghai`
- 第 1 周周一：`2026-08-31`
- 长安校区节次：
  - 1-2 节：08:30-10:10
  - 3-4 节：10:30-12:10
  - 5-6 节：12:20-13:50
  - 7-8 节：14:00-15:40
  - 9-10 节：16:00-17:40
  - 11-12 节：19:00-20:40
  - 第 13 节：20:40-21:25

第 1 周日期依据学校 2026 年 8 月 31 日开学检查报道；节次时间依据西北工业大学教务部公布的长安校区作息时间。

## 数据说明

- `schedule_manifest.json`：标准化课表清单。
- `coverage.json`：21 个非空 PDF 单元格的双向覆盖清单。
- `西北工业大学_2026-2027秋季课表.ics`：可直接导入的日历文件。
- `docs/calendar.ics`：订阅站点使用的同内容日历文件。
- `validate_calendar.py`：检查 CRLF、75 字节折行、事件数量、UID 唯一性和清单一致性。

课表 PDF 的备注“粘性流体力学 M07M11040.01 (13~20)”没有星期、节次和地点，因此不生成事件。日历不包含源文件发布之后的调停课、节假日或临时地点通知。

## iPhone 订阅

发布 `docs/` 为 HTTPS 静态站点后，在 iPhone Safari 打开站点并点“订阅到 iPhone 日历”。也可在“设置 → App → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历”中粘贴页面显示的 HTTPS 地址。
