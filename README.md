## 数据说明

- `schedule_manifest.json`：标准化课表清单。
- `coverage.json`：21 个非空 PDF 单元格、4 条先前地点通知及本次课程通知的双向覆盖清单。
- `西北工业大学_2026-2027秋季课表.ics`：可直接导入的日历文件。
- `docs/calendar.ics`：订阅站点使用的同内容日历文件。
- `validate_calendar.py`：检查 CRLF、75 字节折行、事件数量、UID 唯一性和清单一致性。

## iPhone 订阅

发布 `docs/` 为 HTTPS 静态站点后，在 iPhone Safari 打开站点并点“订阅到 iPhone 日历”。也可在“设置 → App → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历”中粘贴页面显示的 HTTPS 地址。

后续更新沿用同一订阅地址和已存在事件的 UID。已订阅的 iPhone 无需重新订阅；系统会按其刷新周期获取变更。
